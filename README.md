## 📌 About the Project

This project predicts whether a **person has heart disease or not** based on medical data.

👉 The goal is to assist in early detection of heart disease using **Machine Learning Classification Models**.

---

## 🎯 Features Used

- 👤 Age  
- 🚻 Gender  
- ❤️ Chest Pain Type  
- 🩺 Blood Pressure  
- 🧪 Cholesterol  
- ⚡ Maximum Heart Rate  
- 🧠 Other medical attributes
